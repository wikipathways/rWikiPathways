Colorize Pathway Script

Source: R/colorize_pathway.R

Draft documentation page for pathway image colorization from differential expression results.

Usage

Rscript R/colorize_pathway.R --tsv input.tsv --species "Homo sapiens"

Arguments

This script allows to use command line flags and environment variables.

ArgumentEnvironment variableDescription
--tsvWP_TSV_FILEPath to input TSV with columns gene and log2FoldChange.
--speciesWP_SPECIESSpecies name recognized by WikiPathways.
--min-genesWP_MIN_GENESMinimum matching genes required per pathway. (default: 3)
--output-dirWP_OUTPUT_DIROutput directory for images and tables. (default: ./pathway_images)
--limitWP_LIMITMaximum number of pathways to process; use 0 for all pathways. (default: 5)

Input

A TSV file with columns gene, baseMean, log2FoldChange, lfcSE, pvalue, and padj as defined by differential gene expression analysis performed with DESeq2.

Output

Generated pathway images and summary tables in the output directory.

Note: This script will produce an unpredictable number of output files, depending on the number of pathways that meet the criteria. The output directory will contain a summary file and a plot for each processed pathway. The colour intensity will depend on the log2 fold changes: in blue for upregulated genes and red for downregulated genes.
